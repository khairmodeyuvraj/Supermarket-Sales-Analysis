# Supermarket Sales Analysis

## 📌 Project Overview

The objective of this project is to analyze Superstore sales data and extract meaningful business insights using Python and data visualization techniques. The project follows the complete data analysis workflow, including data cleaning, exploratory data analysis (EDA), visualization, and business insight generation.

---

## 🎯 Objectives

- Clean and preprocess the sales dataset.
- Analyze monthly revenue trends.
- Identify top-selling products.
- Perform profit analysis across categories.
- Visualize sales distribution across different regions.
- Generate actionable business insights using Exploratory Data Analysis (EDA).

---

## 📂 Dataset

- **Dataset Name:** Sample Superstore Dataset
- **Source:** Kaggle
- **File Used:** `Superstore.csv`

---

## 🛠️ Technologies Used

## 💡 Key Business Insights
